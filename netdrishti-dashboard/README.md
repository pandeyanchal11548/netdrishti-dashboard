# NetDrishti Web Dashboard

React + TypeScript + Vite. Eight feature pages, each on its own route.

## Scripts

- `npm start` – dev server (http://localhost:5173)
- `npm run build` – type-check and production build
- `npm run lint` – ESLint
- `npm run format` – Prettier
- `npm test` – Vitest (component and utility tests)

## Folders

`src/app` routing and navigation · `src/pages` one component per route · `src/features` feature code (later) ·
`src/components` shared UI · `src/services` API functions (later) · `src/utils` formatting helpers · `src/styles` design tokens
